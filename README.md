# rainsave-almaty
RainSave Almaty

Ғылыми-инженерлік жоба және Алматы қаласы әкімдігіне арналған ұсыныс платформасы.

Бұл веб-страница Алматы қаласындағы №12 мамандандырылған гимназияның 11-сынып оқушылары Алиқұл Арайлым мен Сманова Еркенұрдың ғылыми-зерттеу жұмысы аясында жасалды. Жобаның ғылыми жетекшісі — химия пәні мұғалімі Паримбекова А.М.
Жобаның негізгі мақсаты:
Алматы қаласындағы нөсер суларының химиялық құрамын тексеріп, оларды тазалап қайта пайдалану арқылы ауыз суды үнемдеу жүйесін негіздеу.
Зерттеу барысында орындалған жұмыстар:
Алматы қаласының 3 түрлі аймағынан жауын суының сынамалары жиналды.
Зертханада pH, TDS минералдануы, қаттылық, нитраттар мен сульфаттар мөлшері анықталды.
Сүзгіленген жауын суының көгал суаруға, аула тазалауға және санитарлық жүйелерге жарамдылығы дәлелденді.
Мектептер мен мемлекеттік мекемелерге арналған 6 сатылы RainSave сүзгі жүйесінің моделі әзірленді.
Қолданылған технологиялар:
HTML5 және Tailwind CSS — веб-беттің визуалы мен адаптивті дизайны.
Chart.js — зертханалық көрсеткіштерді салыстыратын диаграммалар.
Leaflet.js — су сынамалары алынған орындар көрсетілген интерактивті карта.
GitHub Pages — жоба хостингі.
